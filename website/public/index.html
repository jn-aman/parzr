Names

Built to respect names.

Names are proper nouns. Type aman jain or thanks, priya in lowercase and Parzr suggests the capital, Aman Jain and Priya, but never respells the name. Real typos still get fixed. And it learns the names that matter to you.

  • From your UndoUndo a change to a name and Parzr remembers.
  • From IgnoreIgnore a mark once and it stays ignored.
  • From macOSIt reads the system dictionary and, only if you opt in, your Contacts.
  • This is a nameOne button on the card teaches it directly.

Compatibility

Works where you write.

No extension required. Parzr is honest about what has been tested: TextEdit has passed capture, selection, formatting and Undo end to end. Other apps use the same Accessibility route and have not all been tested.

Google Docs

Google Docs draws text on a canvas, so macOS Accessibility sees no document text there. Option+Space copies your selection, checks it, and pastes the fix. Automatic underlines are not available in canvas editors.

Optional extras for developers

  • Browser extensionChrome, Edge, Brave, Chromium and Firefox. Activated per page, for DOM-level editing.
  • VS Code extensionProse in plaintext, Markdown and commit messages, plus forks where their APIs permit.
  • Language serverNeovim, Emacs, Zed, Helix and Sublime, set up per editor.

Safari uses the native accessibility route; there is no Safari extension. Read the full evidence table.
