How it works

Click the word.
Fix the sentence.

  1. 01
    Underlines appear as you pause.Parzr checks the paragraph you are in once you stop typing.
  2. 02
    Click the word itself.The whole word is the click target.
  3. 03
    See the whole fix at once.Nothing changes until you accept it.
  4. 04
    One keystroke. Done.Corrections apply as small edits, and Undo still works.

Privacy

Your words never leave this Mac. No account. No cloud. No telemetry. No HTTP server.

  • 0bytes sent

    Writing stays in memory on this Mac.

    No account, no telemetry, no HTTP service and no writing logs. The browser extension hands text only to the native process on this Mac.

  • 593MB model on device

    Qwen3.5-0.8B Q5_K_M, run with llama.cpp on Metal.

    The model, runtime and attributed frequency data ship inside the app and the DMG. Idle model state unloads after 30 seconds.

  • 100% offline after install

    A Rust engine does the grammar work.

    Nothing downloads at runtime. Dependency downloads happen when you build from source; writing analysis runs offline.

Writing modes

One sentence.
Five ways to say it.

OriginalIllustrative example

Grammar, spelling and punctuation run in every mode.

Original
hi john, i was wondering if maybe you could possibly send me that report whenever you get a chance, thanks alot
Fix Small fixes. Same voice.
Hi John, I was wondering if maybe you could possibly send me that report whenever you get a chance. Thanks a lot.
Professional Clear, composed, considered.
Hello John, could you please send me that report at your earliest convenience? Thank you.
Friendly A little warmer. Still you.
Hi John! Could you send me that report when you get a chance? Thanks so much!
Concise Fewer words. Full meaning.
Hi John, could you send me that report when you can? Thanks.
Direct Get straight to the point.
John, please send me that report. Thanks.

Illustrative example, written by hand to show how modes differ. Real output depends on your text.

Google Docs

Google Docs draws text on a canvas, so macOS Accessibility sees no document text there. Option+Space copies your selection, checks it, and pastes the fix. Automatic underlines are not available in canvas editors.

Safari uses the native accessibility route; there is no Safari extension. Browser extensions are activated per page. Read the full evidence table.

Open source

Read every line.

Apache-2.0. A Rust grammar engine, a Swift app and a local model, all in one public repository. Every rule ships with a positive and a negative example, and its provenance.

  • Rust grammar engineTokenizer, phrase and context rules, spelling, edit planning.
  • Swift appSwiftUI and AppKit shell with native menus and cards.
  • Local modelQwen3.5-0.8B Q5_K_M through llama.cpp and Metal.
