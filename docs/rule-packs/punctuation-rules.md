# Punctuation pack: coverage map

`engine/rules/packs/punctuation-rules.json` holds the punctuation rules (id prefix `punct.`), generated by `scripts/punctuation-pack/build.py` from the word lists next to it. Every rule has a required literal for the prefilter, a positive and a negative example written for it (the negatives carry the near misses: the predicative use, the hyphenated form already right, the pronoun, the quoted word), and a confidence between 0.80 and 0.95. Rules touch only the characters that change (a space, a hyphen, an apostrophe, a comma), so the writer's words are never respelled.

## What the engine already does (read first)

Most punctuation is Rust, not regex (`engine/src/punctuation.rs`, `marks.rs`, `structure.rs`, `clauses.rs`, `clause_repairs.rs`). The pack adds only what a regex can add safely without fighting it. The Rust checks, for reference:

| Check | Engine id |
|---|---|
| space before `, ; : ! ?` after a letter, missing space after `, ; :` between letters | `punctuation.before_mark`, `punctuation.after_mark` |
| space before a period, space inside parentheses, a word glued to a parenthetical (`me(if you can)`) | `punctuation.before_mark`, `punctuation.bracket_spacing` |
| a period glued to the next sentence (`end.Next`) for a fixed list of sentence openers | `punctuation.after_sentence_mark` |
| doubled marks (`,,` `.,` `?.`), `etc..`; `...`, `?!`, `!!` kept | `punctuation.doubled_mark` |
| comma splices, run-ons, fragments cut off by a period, commas before `but`/`so`/`and` between clauses, commas after `however`/`moreover`/`for example`/…, introductory clauses, greeting commas | `punctuation.comma_splice`, `run_on`, `fragment`, `coordinated_clauses`, `introductory_comma`, `greeting_comma`, `parenthetical_comma`, `extra_comma` |
| dates (`October 20, 1861`), weekday commas, `; however,` | `punctuation.date_comma`, `introductory_comma` |
| a missing question mark, a statement ended with `?` | `punctuation.question_mark`, `indirect_question` |
| colons after a verb or preposition before a lower-case list, semicolons used as colons or commas, `as follows` | `punctuation.colon_after_verb`, `semicolon`, `colon_before_list` |
| quotation marks left open | `punctuation.open_quote` |
| hyphens: twenty-one, `a 30-day trial`, `a long-term plan` (a list of 45 compounds), `ex-wife`, `cloud-based`, `well-known`, no hyphen after `-ly`, `years old`, `log in` as a verb | `punctuation.compound_hyphen`, `number_hyphen`, `ly_hyphen`, `phrasal_verb_hyphen` |
| apostrophes: `two dog's`, `the 1990's`, `my sisters wedding`, `a days rest`, `Sarahs laptop`, `everyones`, `your's`, accent marks | `punctuation.apostrophe` |

## Coverage map

Legend: **rule** = in this pack (family prefix `punct.<family>.`); **base** = already handled by the engine; **left** = deliberately not a rule, with the reason.

### Apostrophes

| Construction | Status |
|---|---|
| plural with an apostrophe after a number or quantifier (`two dog's`) | base (`punctuation.apostrophe`) |
| plural acronym before a plural verb (`The PDF's are attached`) | left: the engine protects acronyms as names, an edit inside one is dropped |
| family names (`The Smith's are coming`) | rule `apostrophe.family_plural` |
| verbs given an apostrophe (`he work's`, 56 verbs) | rules `apostrophe.verb_*` |
| decades, digits (`1990's`) | base |
| decades, spelled out (`the sixty's`) | rules `apostrophe.decade_*` |
| `its'`, `hers'`, `ours'`, `yours'`, `theirs'`, `his's`, `mine's` | rules `apostrophe.its_stray`, `*_stray`, `his_stray`, `mine_s` |
| `your's` `their's` `our's` `her's` | base (`usage.possessive_pronoun_apostrophe`, `punctuation.apostrophe`) |
| time words (`last years budget`, `this weeks agenda`, `yesterdays news`) | rules `apostrophe.<time>_*` (22 time words) |
| `a days work`, `todays` | base |
| counted units (`two weeks notice`, `five years experience`) | rules `apostrophe.units_*` (8 nouns) |
| plural possessive typed wrong (`childrens'`, `womens'`, `mens'`) | rules `apostrophe.*_plural_apostrophe`; `apostrophe.mens` for `mens room` |
| `someone elses`, `one anothers`, `each others'`, `a friend of mines` | rules (`apostrophe.*_elses`, `one_anothers`, `each_others_plural`, `of_mines`) |
| holidays (`Mothers Day`, `New Years Eve`, `April Fools Day`) | rules `apostrophe.holiday_*`; `St Patricks Day`, `Petes sake`, `Murphys law`, `Hobsons choice` left: the name guard drops an edit inside a name |
| fixed phrases (`a stones throw`, `at arms length`, `wits end`, `for goodness sake`, `a birds eye view`, `fools gold`, `devils advocate`, `writers block`, `a masters degree`, `the doctors orders` …) | rules `apostrophe.<phrase>` (32) |
| `my sisters wedding` (people list) | base |
| a missing apostrophe on any other noun (`the users guide`) | left: singular or plural possessive cannot be told by a regex |
| `its`/`it's` confusion | left: other packs (`usage.its_*`, confusions) |
| doubled apostrophe in a contraction (`don''t`) and the space in `do n't`, `it 's`, `I 'm` | rules `apostrophe.doubled_*`, `contraction.*` |

### Hyphens

| Construction | Status |
|---|---|
| compound modifier before a noun, curated list (`data driven approach`, `hands on training`, `high risk patients`, `ready to use kit` …) | rules `hyphen.<compound>_modifier` (see the list below) |
| the compounds in `marks.rs` (`long term`, `real time`, `up to date`, `state of the art` …) | base |
| number + unit + noun (`a three story house`, `a 64 bit processor`, `a six figure salary`), `5 minutes break` to `5-minute break`, `in 5-minutes` | rules `hyphen.num_*` |
| `twenty one` | base; `twenty first` … `ninety ninth` (not `second`) | rules `hyphen.ordinal_*` |
| `19th century novel` | rules `hyphen.century_*` |
| prefixes `self-` (70), `ex-` (plurals and 20 nouns), `co-`, `non-` (proper adjectives and acronyms), `mid-` (months, years, decades, nouns), `pre-`, `post-`, `anti-`, `pro-`, `all-`, `re-` before e | rules `hyphen.<prefix>_*` |
| `mother in law`, `bride to be`, `president elect`, `great grandmother` | rules `hyphen.*_in_law`, `*_to_be`, `*_elect`, `great_*` |
| `e commerce`, `x ray`, `t shirt`, `wi fi`, `sci fi`, `no brainer`, `half life` | rules `hyphen.*` (always hyphenated) |
| `e mail`, `re send` (and 19 more `re` + verb) | rules `spelling.e_mail` and `spelling.re_*` (joined; the hyphen form is not required) |
| `-ly` adverb + hyphen, `years-old`, phrasal verbs as verbs (`log-in`) | base |
| the compound is a predicate (`the plan is long term`) | never matched: every compound rule needs a noun right after it |
| `post`/`pro`/`all` + word where the prefix is also a word (`post production`, `all new employees`, `pro life coach`) | left: reads both ways |

### Spacing and marks

| Construction | Status |
|---|---|
| space before a comma or period after a letter | base |
| space before a comma after a year or a closing bracket | rules `spacing.year_space_comma`, `spacing.bracket_space_comma` |
| missing space after a comma between letters | base; after a year or a closing bracket: rules `spacing.year_comma_glued`, `spacing.bracket_comma_glued` |

### Commas, colons, semicolons, questions

| Construction | Status |
|---|---|
| comma after `however`, `moreover`, `therefore`, `for example`, `in fact`, `as a result` … | base (`clauses.rs`, `INTRO_WORDS`, `INTRO_PHRASES`) |
| comma after other openers (`Finally we`, `Of course I`, `Firstly I`, `In my opinion the` …) | left: the comma is optional; 100+ sentences of the clean 30k corpus omit it, so a rule would be a false alarm (a first version was written and dropped) |
| comma splice with `however`, `therefore`, `moreover` | base: splits at a period; no semicolon rule added (a regex cannot tell a full clause from `After the meeting, accordingly, …`) |
| `said, that …` (32 verbs; only when no earlier comma opens a parenthetical such as `, I believe, that`) and `better, than` | rules `comma.after_*_that`, `comma.before_than` |
| colon after `including`, `such as`, `consists of`, `includes` … before a capitalised or numeric item (lower-case items are base) | rules `colon.after_*` |
| a clear wh-question ended with a period (`Where is the file.`) | rules `question.*`; yes/no questions left (a polite request often ends in a period) |
| missing `?` | base |

### Left out because the base rules disagree (found by running every positive through the engine)

* `win win`, `one to many`, `many to many`, `walk in closet`, `eco friendly`, `take out`, `pick up`, `walk through`, `start up` as modifiers: `grammar.repeated_word`, `grammar.noun_number`, `det.the_closet`, `spelling.delete_index` and the confusions pack rewrite or delete the same words.
* `childrens'` / `womens'`: `spelling.common_misspelling` already respells the word and keeps the stray apostrophe.
* `all things considered the team`: `punctuation.comma_splice` splits it at a period.
* the contraction `re` + verb rules and the `re` hyphen rules must not match after an apostrophe (`we're thinking` once became `we'rethinking` and the engine did not stabilize); they now require a non-word, non-apostrophe character before `re`.

### Known base issues found (reported, not fixed)

* `She doesn't have the permission set configured.` is split by `punctuation.run_on` into `She doesn't have. The permission set configured.` (the engine reads `permission set` as a new clause).
* `He run's every day.` becomes `He runs's every day.`: `grammar.present_singular_*` matches `run` before the apostrophe and leaves `'s`.
* `It is a hands-on experience.` (correct) becomes `a hand-on experience` through `grammar.article_number`; `a results-oriented manager` becomes `result-oriented`.
* `She is someone elses problem.` becomes `someone else problem.` through `spelling.delete_index`.
