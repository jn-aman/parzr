# Capitalization pack: coverage map

`engine/rules/packs/capitalization-rules.json` holds the capitalization rules that are not sentence starts (ids `caps.*`, category
Capitalization, with school subjects as Style suggestions). It is generated by `scripts/rule-pack-gen/capitalization/` (`python3 build.py`, then
`python3 verify.py`) from word lists and a few hand-written frames, because the category is mostly lexical: one rule per name, one frame
per word that is also an ordinary word. Every rule has its own positive, a negative that holds the near misses (the common-noun reading,
the correct spelling, a file name, a hashtag, a handle, an identifier, a URL), a required literal for the prefilter and a confidence
(0.84 to 0.93; brands and acronyms 0.88 to 0.92, frames around a common word 0.84 to 0.90). `correct-1.txt` next to the generator holds
correct sentences (written for this pack) that no rule may touch; `verify.py` runs every positive and negative, and those lines,
through the real engine.

## What the engine already does (and the pack does not repeat)

| Construction | Handled by |
|---|---|
| Sentence starts, after `.`, `?`, `!` and at line starts, chat included (`grammar.sentence_capitalization`), with `ok` written `OK`, chat shorthand and code lines left alone | base, `engine/src/lib.rs` |
| `i`, `i'm`, `i'd`, `i've`, `i'll` (`grammar.personal_pronoun`) | base |
| Days and the months that are never ordinary words (`grammar.calendar_capitalization`); `march`, `may`, `august` in a date frame (`capitalization.rs`) | base |
| About 600 proper nouns typed in lowercase: most countries, US states, Canadian provinces, big cities, continents, languages and nationalities, holidays (Christmas, Easter, Diwali, Ramadan, Hanukkah), religions, brands (`iPhone`, `GitHub`, `YouTube`, `LinkedIn`, `WhatsApp`, `PowerPoint`, `JavaScript`, `TypeScript`, `macOS`, `iOS`, `ChatGPT`, `OpenAI`, `PayPal`, `TikTok`, `Instagram`, `Facebook`, `Microsoft`) in `engine/rules/proper-nouns.txt`, and brand casing from the lexicon (`spelling::canonical_case`) | base (`grammar.proper_noun_capitalization`) |
| A season capitalized inside a sentence (`in Summer`), a stray capital after a colon, a stray `You` | base (`capitalization.rs`) |
| A name candidate is never respelled; case-only edits are allowed | base (name guard), which the pack relies on |

## Not rules, and why

- **Seasons, compass points and subjects stay lowercase** (`in summer`, `drive north`, `she studied physics`): the engine already lowercases a stray capital season; the pack lowercases directions in a travel frame and subjects after a study verb. `the South`, `the East Coast`, `the Midwest` (a region) are left capitalized or capitalized by rule.
- **`god`, `heaven`, `hell`, `lord`**: reference decides; no rule.
- **`internet`, `web`, `email`**: both spellings are accepted.
- **ALL CAPS** (shouting, headings, `NASA`): never touched; every rule is case-sensitive.
- **A capital after a colon, after `?` or `!`, a quotation or a parenthesis**: sentence starts and colon lists belong to the engine; a capital inside parentheses is the writer's choice.
- **Mid-sentence random capitals** (`the Report is Ready`): title case and emphasis look the same; no rule.
- **`ok` / `OK`**: written `OK` at a sentence start by the engine; elsewhere both are accepted.
- **`i.e.`, `e.g.`, `etc.`**: lowercase is right.
- **`french fries`, `english muffin`**: the engine capitalizes `French` and `English` everywhere, which the major dictionaries do too (`French fries`, `English muffin`); the pack adds nothing.
- **`docker`, `git`, `npm`, `kubectl`, `brew`, `pip`** typed in lowercase: command names; the engine protects the command line, and prose that names the tool is left alone.
- **Tokens that mix letters and digits** (`html5`, `b2b`, `ps5`, `m1`, `q1`, `gpt4`) and **file names** (`node.js`, `package.json`, `app.js`): the engine protects them from any edit.
- **Family words as names** (`call mom`), **`wifi`**, **a greeting followed by a capital** (`Hello Ana, Hope you're well`) and **`login id`**: rules were written for them and dropped after the everyday gate, whose reference keeps all four as typed.
- **`bitcoin`, `ethereum`, `internet of things`, `gif`, `ram`, `rom`, `lan`, `pin`, `os`, `it`, `us`, `un`**: accepted lowercase, or ordinary words.
- **Names that are also ordinary words** (`nice`, `reading`, `bath`, `hull`, `salem`, `jackson`, `charlotte`, `orange`, `bordeaux`, `genoa`, `seville`, `damascus`, `havana`, `mobile`, `ford`, `target`, `square`, `sketch`, `postman`): a capital would be wrong in the ordinary reading and there is no frame to tell them apart.
- **Subjects the name tagger protects** (`Maths`, `Philosophy`, `Anthropology`, `Algebra`, `Calculus`): the engine never lowercases a word it takes for a name; the rules were written, never fired, and were dropped (`skipped-ids.txt`).
- **Phrases whose first word the engine already capitalizes** (`indian ocean`, `vietnam war`, `french revolution`, `european commission`, `cambridge university`): with only the lowercase spelling counted as an error, the first word is fixed by the gazetteer and nothing is left; 32 such rules were written and dropped.
- **Quoted and bracketed words** (`"paris"`, `[api]`): never matched, so JSON keys, TOML tables and quoted examples are left as typed.

## What the pack measured

Without the pack and with it (same build otherwise), Fix mode, American English:

| Check | Without | With |
|---|---|---|
| 30k clean sentences (`mining.jsonl`, `clean: true`, mostly lowercase tweets): rule hits | 0 | 68 rules, 99 hits; every one a lowercase proper noun or acronym (`on xbox live`, `nba playoff game`, `gracias jesus`, `northern ireland`): true positives |
| 25k corrected references of non-clean rows (own check, well-cased Wikipedia and GitHub prose): rule hits | 0 | 56 rules, 76 hits; the false alarms it showed were removed (see below); the rest are lowercase `html`/`css`/`url`/`json`, `king Jehu`, `a tumblr page`, `gaelic football`, `1234 bc` |
| English 1000 / 2000 sets | exact | exact (1000/1000 and 2000/2000, controls kept) |

| Held-out DEV, rules / Smart grammar | 77.9% / 89.2% fixed, 0.0% false alarms | 78.0% / 89.3% fixed, 0.0% false alarms |
| Typo-fuzz DEV, rules / Smart grammar | 79.5% / 84.0% fixed, 0.0% false alarms | 79.5% / 84.4% fixed, 0.0% false alarms |
| Names benchmark | typo recall 96.08%, 0.03% damaged | identical |

What the gates removed from the pack: family words as names, `wifi`, a capital after a greeting comma and `login id` (everyday gate: the owner's
reference keeps them), lowercase acronyms one typo from a frequent word (`iit`, `wwe`, `wto`, `usd`, `uae`, `gpt`, `gst`, `iot`, `ngo`, `okr`, `oled`: typo-fuzz DEV),
`cms` (centimetres), `nda` (Indonesian), capitalized `Saas`, `Roi`, `Uri` (names), `north pole` (magnets), `northern hemisphere`, `cold war`, `stone age`,
`a bible study group`, `a google search`, `father Robert` (a relative), `coach` (AP lowercases it), `and chancellor Jan Zamoyski` (an apposition), `0.5 pc`
(parsec), `import numpy as np`, `heroku login` and `from json import loads` (code: developer tools are capitalized only after a prose word and before a stop,
a function word or a plain noun).
