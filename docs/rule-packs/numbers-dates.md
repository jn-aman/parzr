# Numbers, dates, times, units and currency pack (`num.`)

`engine/rules/packs/numbers-dates.json` is generated by `scripts/rule-pack-gen/numbers-dates/` (families: ordinals, clock,
quantity, money, units, dates, misc). `build.py` checks every rule as it is built: its positive must change to exactly the
stated correction (the generator emulates the engine's single edit), and its negative must not match at all. Run
`python3 build.py --dump` in that folder, then `python3 scripts/check-rule-packs.py engine/rules/packs/numbers-dates.json`
and `cargo test --release rules::`. `check-correct.py` runs every rule over `correct-1.txt`, correct sentences written for
this pack (near misses: modifiers, idioms, hyphenated forms, decimals, stone weights, modulo, identifiers); none may match.
`verify.py ENGINE` runs every positive and negative through the built engine.

## How the engine treats numbers (and what that rules out)

The engine protects every digit run (`\b\d+(?:[.,:/-]\d+)*\b`, so "5-10", "2024", "3:30" and "1,000.50" are never edited),
tokens such as "mp3" and "km/h", and an edit that overlaps a protected span is dropped. So the pack only ever edits the
words and signs around a number: the target is the suffix ("1th" → "1st": the digit run "1th" is not protected because
there is no word boundary inside it), the unit, the sign or the space. This rules out anything that must rewrite the digits
themselves ("5$" → "$5", "from 5-10" → "from 5 to 10", "I have 20 years" → "I am 20 years old").

## Coverage map

Construction, then the rule ids (`num.` prefix) or the base/engine rule that already covers it.

### Ordinals

| Construction | Rules |
|---|---|
| "1th", "21th", "31th" | `ord.th_for_1`; "1nd", "21rd" → `ord.th_for_1b` |
| "2th", "22th"; "2st", "22rd" | `ord.th_for_2`, `ord.th_for_2b` |
| "3th", "23th"; "3st", "23nd" | `ord.th_for_3`, `ord.th_for_3b` |
| "11nd", "12rd", "13rd" (teens take "th") | `ord.th_after_teen` |
| "4rd", "5nd", "20rd" | `ord.th_after_other` |
| "11st", "12st", "13st" | **left out**: "12st" is twelve stone in British weights |
| "twelveth", "twelvth", "twentyth", "ninetyeth", "eightith", "fourtieth" | `ord.word_twelfth`, `ord.word_ieth`, `ord.word_fortieth` |
| "fiveth", "nineth", "eigth", "elevent", "hundreth", "secound", "thrid", "fith" | covered by the engine's spelling pass |
| "forth time" for "fourth time" | `word.fourth_forth` ("back and forth" is untouched) |
| "the 5 of May", "the 22 of July" (no ordinal ending) | `ord.day_of_month_st/nd/rd/th` |
| "the 20 century" | `ord.century_st/nd/rd/th` |
| "on the 3 floor" | `ord.floor_st/nd/rd/th` |
| "1st of January 2024", "January 1st" | **left out**: correct in British writing and speech |
| "in 20th century" (missing "the") | `date.century_missing_the` ("20th-century art" stays) |
| "in 1990s" (missing "the") | `date.decade_missing_the` ("in 1990s Britain" stays) |

| Construction | Rules |

| "12 am midnight", "12 pm noon" | `clock.midnight_am`, `clock.noon_pm` ("12 noon", "12 midnight" are correct and untouched) |

| "half past five o'clock" | `word.half_past_oclock` |
| "5pm" → "5 pm" (Style) | **left out on purpose**: the everyday regression set and the engine's own tests treat "5pm" as correct (a trial rule made 26 everyday items newly wrong and failed two engine tests), and a rule limited to Professional mode never reaches the user (tone is model-driven and the pack rule is `tone.withheld`) |
| "9 a.m. to 5 pm" mixed styles | `clock.dots_mixed_pm`, `clock.dots_mixed_am`, `clock.plain_mixed_pm`, `clock.plain_mixed_am` |

| "between 5 to 10" | covered by `prep.between_numbers_to` |

| "5 – 10 dollars" hyphen versus en dash | **left out** on purpose (typography, both fine) |
| "mins", "secs", "hrs" | **left out**: accepted shorthand |

| Construction | Rules |
|---|---|

## False-alarm policy for this pack

Every rule that can be written around a following noun (a modifier such as "a 5 hour trip") requires the unit to close the
phrase (punctuation, the end, or a function word such as "away", "ago", "of", "from"); the singular-after-count rules never
fire on a hyphenated or noun-modifying use. Style rules ("20 %") and the Indian-English abbreviation rules (Register: "kms", "kgs") are suggestions at 0.7 to 0.75; Redundancy rules sit at 0.8.
