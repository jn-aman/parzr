# Word-order pack (`order.`)

`engine/rules/packs/word-order.json` is generated by `scripts/rule-pack-gen/word-order/gen.py` (modules: questions,
embedded, adverbs, negation, inversion, passives, phrases, adjectives, extras). Each rule is checked as it is built: its
positive must change to exactly the stated correction (the generator emulates the engine's single edit and its two-edit
`moved` move) and its negative must not match at all. Run the generator, then
`python3 scripts/check-rule-packs.py engine/rules/packs/word-order.json` and `cargo test --release rules::`.

Every question rule needs either a sentence-initial wh-word **and** a closing "?" (direct questions), or an asking word
before the wh-word and no "?" requirement (embedded questions). So "I know what you want." and "What you want is a
break." are never touched, and an echo question ("You want what?", "He works where?") has no sentence-initial wh-word.

## Coverage map

Construction, then the rule ids (`order.` prefix) or the base/engine rule that already covers it.

What the rules deliberately skip, found by running the draft pack over real-error rows: a subjunctive "that he not make edits" (so "that" does not start a clause for the "not" rules), a question inside a quotation or after a comma ("When he asked her 'why…?', she…"), coordinated objects ("I love a lot my mother and my father"), and "the conclusion is arrived at".

### Direct questions

| Construction | Rules |
|---|---|
| wh + pronoun + auxiliary or modal ("Where he is going?", "Why you are late?", "How I can do this?", "What time it is?", "When you will come?", "Why you didn't tell me?") | covered by the engine (`grammar.question_order`) |
| wh + you/they/we/I + verb, no "do" ("What you want?", "Where they live?") | covered by the engine (`grammar.missing_auxiliary`) |
| wh + he/she/it + third-person verb ("Where he works?", "How it looks?") | `q3sg.<verb>` (89 verbs) |
| wh + pronoun + past verb ("Why they left?", "What you found?") | `qpast.<verb>` (84 verbs) |
| wh + determiner + noun + be / modal / perfect ("Why the server is down?", "When the meeting will start?", "Why the server has stopped?") | `q_np_be.<wh>`, `q_np_modal.<wh>`, `q_np_perfect.<wh>` |
| "What means this?", "What mean these words?" | `what_means`, `what_mean_singular`, `what_mean_plural` |
| "How looks it?" (12 verbs), "How much costs it?", "How much it costs?" | `how_inverted.<verb>`, `how_much_costs_inverted`, `how_much_np_costs` |
| "What time starts the movie?" / "When the class starts?" (9 verbs each) | `time_verb_first.<verb>`, `time_noun_first.<verb>` |
| "Where is located the station?", "How is spelled your name?" (participle moved after the subject) | `passive_q.<participle>` (12) |
| "Where can be found the form?" | `passive_modal_q.<participle>` (7) |
| "Which one you want?", "What colour you like?" (30 verbs) | `wh_noun_do.<verb>` |
| "Why not you come?", "Why you not coming?", "Why you not call me?" | `why_not_you`, `why_you_not_ing.*`, `why_i_not_ing`, `why_you_not_verb.plural`, `why_he_not_verb.singular` |
| "Since when you are here?" | `since_when` |
| "There is any problem?" | `there_any_question.<be>` |
| yes/no questions by intonation ("You are coming?", "You want coffee?") | **left out**: correct informal English |
| "Who you are?", "What you mean?" | covered by the engine |

### Embedded (indirect) questions

| Construction | Rules |
|---|---|
| wh + be / modal + pronoun or determiner noun after know, tell, ask, wonder, explain, remember, see … ("Do you know where is he?", "I wonder what is the time", "Tell me where are you") | covered by the engine (`grammar.embedded_question_order`) |
| the same after clue, curious, show, decide, figure out, learn, care, notice, describe, imagine, doubt, confirm, determine, discover, mind | `emb_aux.<word>` (15) |
| after "the question / problem / issue / point is …" | `noun_is_question.<noun>` (10) |
| wh + is/was + a name ("Do you know who is Sarah?") | `emb_name.is`, `emb_name.was` |
| doubled "do" ("I wonder what do you want") | `emb_do.<wh>` (8) |
| doubled "does" / "did" with a verb ("how does it work", "why did he leave") | `emb_does.<verb>`, `emb_did.<verb>` |
| "if / whether" + aux + subject ("Let me know if can you come", "I wonder if will it rain") | `emb_if.<aux>` (13), `emb_if_does.<verb>`, `emb_if_did.<verb>` |
| "If" at the start of a clause ("If can you, call me", "If do you like it") | `if_inversion.<aux>` (16), `if_do` |

### Passives of intransitive verbs

| Construction | Rules |
|---|---|
| "was / were / been happened, occurred, arrived, died, existed, appeared …" | covered by the tense pack (`tense.intransitive_passive.*`) |
| "It is happened" → "It happened" (happen, occur, appear, emerge); "The parcel is arrived", "is died", "is disappeared", "is vanished" → "has …"; "got happened" | `intransitive.is_*`, `intransitive.are_*`, `intransitive.am_*`, `intransitive.got_*` ("is arrived at" and "to be arrived at" are real passives and are left alone) |
| "It will be happened", "to be occurred" (not arrive) | `intransitive.be_*_modal` |
| "is existed", "is belonged to", "was belonged to", "was / been disappeared" | `intransitive.is_existed`, `…belonged`, `intransitive.was_disappeared`, `intransitive.been_disappeared` |
| "is gone", "is arrived" in archaic or dialect use | flagged for happen, occur, arrive, appear, disappear, die, vanish, emerge, exist, belong only; "is gone" is left alone |

## Known problems in other layers (not edited here)

- **`grammar.adverb_position` (engine, `clause_repairs.rs`) is wrong for modals**: "I will never miss a meeting." becomes
  "I never will miss a meeting." because "will" passes its verb check. This pack does not build on it, and its own
  examples avoid a modal before the adverb. It should skip modals and auxiliaries.
- It also flags "isn't still" and "aren't still" in "The water isn't still boiling" (no longer boiling), which is correct
  English.
