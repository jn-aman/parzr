# Parzr for VS Code

Offline writing corrections and deliberate tone changes using the local macOS parzr engine. Select prose and run **parzr: Improve selected text**. Review the diff before Apply or Copy. Grammar, spelling, and punctuation run in every mode.

Install Parzr.app in Applications first. Change `parzr.enginePath` for a development bundle. Alt+Space is configurable in Keyboard Shortcuts; avoid a conflict with the native macOS shortcut. Local macOS workspaces only. Code selections require a prose confirmation.

The engine and extension are open source, Apache-2.0. No network model, runtime account or writing telemetry. See the main project's integration documentation for tested compatibility and limitations.
